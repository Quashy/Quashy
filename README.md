## 🛠️ 代表项目

### [OpenClaw4J](https://github.com/Quashy/OpenClaw4J)

一个基于 Java、Spring Boot 和 Spring AI 实现的本地优先 Agent 内核，用于实践 Agent 执行循环、工具调用、MCP 接入、本地记忆和工具安全治理。

- **技术栈：** Java、Spring Boot、Spring AI、SQLite、MCP
- **主要工作：** 核心架构、Agent 编排、工具系统、记忆机制与渠道接入
- **项目特点：** 文件驱动、本地优先、Skill 与 Tool 分离、服务端安全治理

[查看源码](https://github.com/Quashy/OpenClaw4J) · [阅读项目说明](https://github.com/Quashy/OpenClaw4J#readme)

### [并击 · 双拼打字练习](https://github.com/Quashy/bingji-shuangpin)

一款面向全拼用户的双拼学习与提速工具，从键位学习逐步过渡到词组和真实文章训练。

- **技术栈：** Next.js、React、TypeScript
- **主要工作：** 产品设计、交互实现、训练逻辑与线上部署
- **项目特点：** 支持多套双拼方案、错题复习、本地训练记录和离线内容回退

[在线体验](https://quashy.github.io/bingji-shuangpin/) · [查看源码](https://github.com/Quashy/bingji-shuangpin) · [设计思路](https://quashy.github.io/2026/from-quanpin-to-shuangpin.html)
